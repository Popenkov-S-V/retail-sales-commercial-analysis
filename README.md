# 🛒 Анализ продаж и оптимизация товаров в ритейле (SQL & Python)

Проект по анализу продаж розничного магазина и наведению порядка в ассортименте. Помогает бизнесу быстро находить самые прибыльные товары и вовремя убирать те, которые не приносят деньги.

## 📈 Что сделано в проекте и какие результаты:
* **Подготовка данных:** Сгенерировал базу данных из 500 покупок за 2025–2026 годы и загрузил её в SQL (SQLite).
* **Анализ прибыли:** Написал SQL-запросы, которые автоматически считают выручку и чистую прибыль магазина по месяцам.
* **Разделение товаров по группам (ABC-анализ):** С помощью продвинутых SQL-запросов (оконных функций) разбил все товары на три группы: А (самые прибыльные), В (средние) и С (убыточные или малоприбыльные).
* **Польза для бизнеса:** Посчитал чистую маржу и объемы продаж в штуках. Это помогло найти скрытые проблемы в ценах и понять, на каких товарах компания теряет деньги.

## 🛠️ Стек технологий и инструменты:
* **Базы данных и SQL:** База данных SQLite, расчеты через группировки (`GROUP BY`), условия (`CASE WHEN`) и сложные оконные функции (`SUM OVER`, `RANK`).
* **Анализ данных:** Язык Python, библиотеки Pandas и NumPy для расчетов.
* **Отчеты для руководства:** Автоматическое создание красивого 6-страничного отчета в формате PDF через библиотеку Matplotlib.
