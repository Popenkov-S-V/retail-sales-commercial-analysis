# 🛒 Анализ розничных продаж и оптимизация товарной матрицы (SQL)

Комплексное аналитическое решение для коммерческого аудита продаж ритейл-сети и многомерной оптимизации товарной матрицы. Система автоматизирует обработку транзакционного массива, оценивает векторы выручки и проводит категоризацию каталога для защиты маржинальности бизнеса.

---

## 📈 Бизнес-метрики и эффективность
* **Синтез данных и ETL:** Программная симуляция транзакционного массива (500 операций за 2025–2026 гг.) и запись в СУБД SQLite.
* **Финансовый аудит (Time-Series на SQL):** Сформированы помесячные витрины для оценки векторов выручки и чистой прибыли.
* **ABC-анализ (Оконные функции SQL):** Реализован классический ABC-анализ с использованием кумулятивных долей для автоматического распределения товаров по группам доходности.
* **Коммерческие инсайты:** Рассчитана чистая маржинальность ценообразования и оценены объемы категорий в натуральном выражении (штуках) для устранения размытия маржи.

---

## 🛠️ Стек технологий и архитектура
* **Инженерия данных и SQL:** СУБД SQLite, глубокое применение оконных функций (`ROW_NUMBER`, `RANK`, кумулятивные суммы `SUM OVER`), группировки и условные конструкции (`CASE WHEN`).
* **Анализ данных:** Python 3.11, Pandas, NumPy, Matplotlib.
* **BI-отчетность:** Автоматизированная программная верстка строгого 6-страничного отчетного PDF-модуля корпоративного формата (11x5 дюймов).
